# Orbit 1.4 launch brief

Use this skill when someone asks for a short introduction to the Orbit 1.4 launch.

1. Read [the product facts](references/product-facts.md) before drafting.
2. Write a headline, three factual highlights, and one next step for the audience.
3. Attribute all dates and numbers to the product facts. If a requested claim is
   not in those facts, label it as unconfirmed rather than inventing it.
4. Finish with a one-sentence caveat that this is a fictional demo release.

Example prompt: "Give me a one-minute Orbit 1.4 launch brief."
